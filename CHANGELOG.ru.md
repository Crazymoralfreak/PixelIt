# История изменений

## [0.0.2] - 2026-11-25

### Изображения из сети

- Новая страница «Из сети». По ссылке: пин Pinterest (в том числе короткая ссылка `pin.it`), любая веб-страница или само изображение. Изображение по прямой ссылке скачивается сразу; для страницы PixelIt показывает найденные на ней изображения, главное стоит первым и уже выбрано. Учётная запись не нужна.
- Поиск в каталогах Openverse и Wikimedia Commons: изображения со свободными лицензиями, под каждым показаны автор и лицензия. Ключ не нужен; текст запроса уходит только в выбранный каталог.
- Выбранное можно скачать, скачать и открыть в редакторе или скачать и добавить в пакет. Загрузка идёт как задача с прогрессом и отменой.
- Ссылка, вставленная через Ctrl+V вне полей ввода, открывает эту страницу с уже заполненным адресом.
- В настройках появилась «Папка для загрузок»; пока она не выбрана, файлы сохраняются в папку `downloads` в данных PixelIt.
- Журнал хранит для каждого скачанного файла адрес источника, а также автора и лицензию, когда они известны; загрузку можно отменить.
- Ассистент и MCP-агенты получили инструменты `find_web_images` и `download_web_image`. Они работают только с разрешением на загрузку из сети и в разрешённых папках; адреса этого компьютера и локальной сети агентам закрыты.

### Редактор

- Новый шаг «ИИ-правка»: подключённый генератор меняет всё изображение или закрашенную кистью область по вашему описанию. Есть сила изменения и кнопка «Другой вариант»; при экспорте используется тот же результат, что показан в редакторе.
- Удаление фона: кистью можно отметить области, которые нужно сохранить.
- У шагов с кистью появились кнопки «Выполнить» и «Изменить область»: шаг запускается, когда область отмечена.
- Ползунок «Размер кисти» виден всегда, а подсказка под ним говорит, какой кнопкой включить кисть. Под указателем показан контур кисти; размер меняют и клавиши [ и ].
- Во время обработки над изображением виден индикатор; ошибка шага остаётся на экране с кнопкой «Повторить».
- Удаление объектов: если модель не запускается на видеокарте, она автоматически переходит на процессор.

### Модели и ИИ

- Ключ сервера сохраняется сразу после вставки и перед запросом списка моделей.
- Если внешние сервисы выключены, PixelIt предлагает разрешить их прямо из запроса; при отсутствии ключа подсказывает, где его ввести.
- Студия: для внешнего сервиса размеры выбираются соотношением сторон (1:1, 3:2, 2:3, 16:9, 9:16). Если сервис отклоняет размер, запрашивается ближайший допустимый.

### Обновления

- PixelIt спрашивает, устанавливать ли новую версию: «Обновить», «Позже» или «Пропустить эту версию». Без согласия ничего не скачивается.

### Зависимости

- Библиотека `zip` обновлена до версии без известных уязвимостей; неподдерживаемая `chrono` убрана из прямых зависимостей.

## [0.0.1] - 2026-11-24

### Просмотр и импорт

- Просмотр папок с миниатюрами, сортировкой и фильтром; размер, формат, глубина цвета и метаданные каждого изображения.
- Открытие перетаскиванием, через диалог, из буфера обмена, из проводника и аргументами запуска.
- Форматы: JPEG, PNG, WebP, AVIF, JPEG XL, HEIC, TIFF, GIF, BMP, ICO, RAW, SVG, PDF, PSD.

### Редактор

- Недеструктивный стек шагов: размер, кадрирование, поворот, отражение, коррекция, фильтры, водяные знаки, аннотации.
- Сравнение «до и после», отмена и повтор, оценка размера файла и сравнение форматов перед сохранением.
- Удаление фона, увеличение, удаление объектов и восстановление лиц на локальных моделях.

### Пакетная обработка

- Очередь файлов и папок с параллельной обработкой, паузой, отменой и оставшимся временем.
- Рецепты: готовые и свои, импорт и экспорт одним файлом.
- Целевой размер файла, подбор качества по визуальному сходству, автоматический выбор лучшего формата.
- Наблюдаемые папки: новые изображения обрабатываются выбранным рецептом.
- Журнал с отменой: созданные файлы уходят в корзину, заменённые возвращаются.

### Инструменты

- Наборы иконок, обложки для соцсетей, адаптивные наборы для сайта с готовым HTML.
- Коллаж, PDF из изображений, анимация GIF, WebP и APNG.
- Поиск одинаковых и похожих изображений.
- Снимок экрана по горячей клавише.

### Модели и ИИ

- Менеджер компонентов: модели скачиваются по запросу и проверяются по контрольной сумме.
- Генерация изображений через ComfyUI, Forge, встроенный stable-diffusion.cpp или внешний сервис по вашему ключу.
- Описания, alt-текст, теги, имена файлов и распознавание текста через модель, понимающую изображения.
- Ассистент с инструментами PixelIt и внешними MCP-серверами.
- Внешние сервисы выключены по умолчанию; перед отправкой изображения PixelIt спрашивает подтверждение.

### Командная строка и MCP

- `PixelIt.exe` выполняет команды из консоли: рецепты, пакет, конвертация.
- `PixelIt.exe mcp` работает как MCP-сервер для Cursor, Claude Desktop и других клиентов.

### Windows

- Значок в области уведомлений, автозапуск, ассоциации файлов, пункт в контекстном меню проводника.
- Автоматическое обновление установленной версии с проверкой подписи; каналы «стабильный» и «бета».
- Portable-версия и интерфейс на 11 языках.
